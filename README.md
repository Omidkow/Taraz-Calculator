# 📊 محاسبه‌گر و برآوردگر تراز کنکور (Taraz Calculator)

این اسکریپت پایتون جهت تخمین دقیق تراز دروس و تراز کل برای داوطلبانی طراحی شده است که در آزمون‌های آزمایشی رشته ریاضی (مانند ماز، مدارس برتر و...) خارج از زمان اصلی شرکت کرده‌اند و کارنامه رسمی برای آن‌ها صادر نشده است.

با وارد کردن درصد و تراز یک کارنامه مرجع (شاخص) در همان آزمون، این برنامه امکان محاسبه دقیق تراز فرضی و رسم نمودار تحلیلی درصد-تراز را فراهم می‌سازد.

---

## 🎯 کاربرد اصلی (Use Case)

اگر آزمون آزمایشی را خارج از زمان رسمی شرکت کرده‌اید:
1. درصد‌های خود در دروس مختلف را وارد می‌کنید.
2. برنامه بر اساس درصد و ترازِ یک کارنامه شاخص از همان آزمون، تراز دقیق هر درس و تراز کل موزون شما را محاسبه می‌کند.
3. در نهایت می‌توانید با تراز بدست‌آمده، رتبه خود را در سایت موسسه مربوطه بررسی کنید.

---

## ✨ ویژگی‌های پروژه (Features)

- محاسبه خطی تراز: تبدیل دقیق انحراف معیار و نمره چی استاندارد بر اساس فرمول موسساتی مانند ماز و مدارس برتر.
- تراز کل موزون: اعمال ضرایب رسمی دروس کنکور (ریاضی: ۱۲، فیزیک: ۹، شیمی: ۷).
- رسم نمودار تحلیلی .

## 🚀 نحوه استفاده (Usage)

۱. پروژه را دانلود یا کلون کنید.
۲. در صورت نیاز، ثابت‌های موسسه مورد نظر (A و B) را در ابتدای کد متناسب با آزمون خود تنظیم کنید (کامنت/آنکامنت).
۳. برنامه را اجرا کنید:

python Tarazsanj_Neshane.py

۴. درصدهای خود را وارد کنید:
Riaziat: 45.5
Fizik: 60
Shimi: 32.5

۵. خروجی ترازها به همراه نمودار تحلیل نمایش داده خواهد شد.
